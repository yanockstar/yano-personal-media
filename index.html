このアプリについて

「yano personal media」は、運営者の矢野和宜が、自分の YouTube・Instagram のチャンネルに自分の動画を投稿・予約するためだけに使う個人用のツールです。一般の利用者向けには提供していません。

取り扱う情報

  • 運営者本人が許可したアカウントの、投稿に必要な許可の情報（アクセストークン）と、チャンネル名・ID だけを扱います。
  • 運営者以外の人の個人情報は集めません。
  • 許可の情報は運営者のパソコンの中だけに保存し、第三者に渡しません。

    • Google のユーザーデータの扱い

    Google API から受け取った情報の利用と他のアプリへの転送は、限定使用の要件を含む Google API サービスのユーザーデータに関するポリシーに従います。

    許可の取り消し

    Google アカウントの「サードパーティ製のアプリとサービス」から、いつでも許可を取り消せます。
